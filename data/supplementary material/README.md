# Supplementary Material Artifacts

This folder contains article-supporting artifacts intended to improve openness,
data availability, and reproducibility for the synchronized submission snapshot.

Snapshot anchor

- Repository commit: `5e59699a9ac0dc688bfe557e936137d46e37f432`
- Snapshot label: `npjdm_submission_snapshot_2026-04-21`

Contents

- `filtered_dataset_binary_classification_analysis.xlsx`
  Main figure-ready aggregate workbook used for descriptive tables and plots.
- `article to population ratio.xlsx`
  Population-normalized corresponding-author country output workbook.
- `supplementary_translational_subset.xlsx`
  Rule-based translational subset workbook.
- `current_full_pipeline_summary.json`
  High-level synchronized pipeline counts and distributions.
- `article_to_population_ratio_summary.json`
  Summary statistics for the population-normalized country analysis.
- `translational_subset_summary.json`
  Summary statistics for the translational subset derivation.

Notes

- Raw Web of Science Core Collection exports are not included here because they
  are subject to Clarivate licensing.
- These files are intended to support verification of manuscript numbers,
  supplementary data packaging, and rerun transparency for the synchronized
  article snapshot.
